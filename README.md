# transmons

A small numerical workbench for simulating a flux-tunable transmon qubit
driven by a train of Single-Flux-Quantum (SFQ) voltage pulses.

The codebase walks the full pipeline from a lumped-element circuit
description through canonical quantisation to time evolution under a
time-dependent drive:

```
Node + Branch + Graph        ->   Multidigraph topology
            |
            v
Circuit (capacitance / inv-inductance matrices)
            |
            v
Transmon (DC SQUID + shunt + coupling capacitor)
            |
            v
Quantize.quantize_transmon  ->   System (H_0, n in charge & energy bases)
            |
            v
CrankNicolsonSolver.solve   ->   level populations P0, P1, P2(t)
```

## Quickstart

```bash
# 1. Set up an environment.
python -m venv .venv && source .venv/bin/activate
pip install numpy scipy pandas matplotlib

# 2. Run the demo simulation.
python main.py
```

`main.py` builds a flux-biased asymmetric SQUID transmon, prints the
charging/Josephson energies, the qubit frequency `f_01`, and the
anharmonicity `alpha`, then drives the qubit with a 150-pulse Gaussian SFQ
train and plots the populations of the lowest three energy eigenstates.

## Layout

| File / dir                | Purpose |
|---------------------------|---------|
| `main.py`                 | End-to-end demo: build, quantise, drive, plot. |
| `Node.py`                 | Auto-id'd electrical-node primitive. |
| `Branch.py`               | `Capacitor`, `Inductor`, `JosephsonElement`. |
| `Graph.py`                | `Multidigraph` topology container. |
| `Circuit.py`              | Generic circuit; assembles reduced C and L⁻¹ matrices. |
| `DCSQUID.py`              | Two parallel JJs, plus `calculate_effective_josephson_energy`. |
| `Transmon.py`             | DC SQUID + shunt + coupling capacitor. |
| `Operator.py`             | Multi-basis quantum operator container. |
| `Wavefunction.py`         | Multi-basis state-vector container. |
| `System.py`               | Bundle of `(circuit, n, H_0)` after quantisation. |
| `Quantize.py`             | Charge-basis Hamiltonian build + diagonalisation. |
| `CrankNicolson.py`        | Cayley-form Crank–Nicolson solver for `H_0 + H_D(t)`. |
| `constants.py`            | `e`, `h`, `hbar`, `FLUX_QUANTUM`, `REDUCED_FLUX_QUANTUM`. |
| `config.py`               | Default Gaussian-SFQ pulse-train parameters. |
| `utils.py`                | `create_gaussian_sfq_pulses`. |
| `riyas_pulses.py`         | RCSJ-based realistic SFQ waveform → `sfq_V_lookup.csv`. |
| `sfq_V_lookup.csv`        | 100k-point downsampled SFQ voltage waveform. |
| `scripts/`                | Scratch/work-in-progress entry points. |
| `docs/`                   | Architecture, physics, and per-module reference. |

## Switching drive sources

By default `main.py` calls `create_gaussian_sfq_pulses` to synthesise an
analytic train of Gaussian voltage spikes.  To use the realistic
RCSJ-derived waveform instead:

```python
import pandas as pd
lookup = pd.read_csv("sfq_V_lookup.csv")
time, external_voltage = lookup["time_s"].to_numpy(), lookup["voltage_V"].to_numpy()
```

The lookup file is regenerated by running `python riyas_pulses.py`.
